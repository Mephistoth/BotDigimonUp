## 🚀 Innovaciones Tecnológicas Clave (v2.8.1)

El núcleo lógico del bot fue reestructurado en esta versión para actuar con un comportamiento estratega y equilibrado, priorizando la identidad visual, el avance recto y la seguridad antibaneo.

*   **🧭 Exploración Equilibrada:** Corrección matemática en el eje vertical (Y) para eliminar el sesgo de movimiento hacia el muro inferior.
*   **➡️ Avance Recto Prioritario:** Preferencia por el carril derecho central libre, usando desvíos solo para evasión o tickets.
*   **🎨 Identidad Visual Pixel Art:** Integración del diseño de Dorumon como ícono de la aplicación e interfaz flotante en Modo Oscuro.
*   **⏱️ Ritmo de Clic Suavizado:** Pausas aleatorias para emular un comportamiento humano y reforzar la seguridad antibaneo.
